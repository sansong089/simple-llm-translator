# Simple LLM Translator

用大模型翻译网页的 Chrome 扩展。翻译质量碾压谷歌翻译和微软翻译，而且不会抽风、不会断连、不会把技术文档翻译成一坨屎。

## 为什么要用这个

**谷歌翻译**：国内经常连不上，翻译结果机械生硬，遇到专业术语直接摆烂。

**微软翻译**：能连上，但翻译质量一言难尽，长句子经常翻车，技术文档更是惨不忍睹。

**这个扩展**：直接调用大模型 API，翻译质量完全不在一个级别。你能明显感觉到，大模型是真的在"理解"句子，不是在做字符映射。技术文档、博客文章、产品说明，翻出来的东西你能直接用，不用再人工润色。

人均一个 API Key 的情况下，使用插件可以免去复制粘贴到网页的麻烦。

## 功能一览

- 右键翻译整个页面，翻译结果直接替换原文，不是浮层叠加
- 选中文字右键翻译，流式显示翻译结果
- 翻译过程中自动跳过代码块、URL、邮箱、变量名
- 滚动加载的新内容自动翻译，动态插入的 DOM 也自动处理
- 对于带格式的文本（加粗、链接等），能保留 HTML 标签完成翻译
- 支持配置多个 OpenAI 兼容 API，随时切换
- API Key 只在后台使用，不下发到网页，不记录日志
- 支持任意 OpenAI 兼容接口：OpenAI、DeepSeek、智谱、月之暗面、本地 Ollama，随便选

## 安装

```bash
git clone https://github.com/sansong089/simple-llm-translator.git
cd simple-llm-translator
npm install
npm run build
```

然后打开 `chrome://extensions/`，开启开发者模式，加载 `dist/` 目录。

## 配置

点击扩展图标 -> 打开配置，填入：

- **Base URL**：API 地址，比如 `https://api.openai.com/v1`
- **API Key**：你的 Key
- **Model**：模型名，比如 `gpt-5.4`

点"测试连接"验证一下，没问题就保存。

## 使用

翻译页面：右键 -> 翻译当前页面，或者点扩展图标 -> 翻译当前页面。

翻译选中文本：选中 -> 右键 -> 翻译选中文本。

停止：右键 -> 停止翻译当前页面。

## 技术栈

TypeScript + Vite + Chrome Manifest V3，零运行时框架依赖。

## 隐私

- API Key 只存在本地，只在后台读取，不下发到网页
- 网页内容只发到你配置的 API，不经过任何第三方
- 不保存任何翻译原文和译文
